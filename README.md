# benson-arthur

This repository is for the edition _King Arthur's Death: The Middle English Stanzaic Morte Arthur and Alliterative Morte Arthure_, edited by Larry D. Benson and Edward E. Foster. It contains:

-	TEI-XML files of the digital edition. Last file updated: 11/20/2026

-	A PDF of the entire edition. Current version: 11/20/2026

-	A Corrections Log, where we record all typographic and editorial corrections made. Current version: 11/20/2026

-	License for use. Current version: 09/18/2024
